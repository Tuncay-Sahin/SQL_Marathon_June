## Project Overview
This repository serves as a professional portfolio for **Quantitative Data Engineering** and **Financial Analysis** using SQL Server. The project focuses on transforming raw transactional data into high-level financial insights, utilizing advanced querying techniques, database encapsulation, and AI-driven optimization.

---

## Key Competencies & Analytical Framework

### 1. Quantitative Analysis & Revenue Modeling
- **Revenue Aggregation:** Computing gross revenue and net transaction volumes through multi-table relational logic.
- **Statistical Benchmarking:** Implementing subqueries to compare individual transaction performance against regional means (e.g., USA market average).
- **Threshold Analysis:** Utilizing `HAVING` and `GROUP BY` to segment high-value asset classes and customer tiers based on quantitative spending patterns.

### 2. Advanced Data Engineering
- **Data Encapsulation (Views):** Constructing reusable, professional reporting layers to simplify complex financial logic.
- **Dynamic Schema Management:** Practical application of `ALTER` and `DROP` operations to maintain an agile database environment.
- **Relational Mapping:** Managing complex joins across `Customer`, `Invoice`, and `Track` tables to ensure data granularity.

### 3. AI-Assisted SQL Optimization
- **Copilot Integration:** Leveraging Generative AI (GitHub Copilot) to audit, refactor, and optimize SQL scripts for better execution performance.
- **Validation Framework:** Benchmarking AI-generated logic against manual SQL development to ensure "Single Version of Truth" (SVOT).
